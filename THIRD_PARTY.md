# Third-party components

The installer downloads these components from their official GitHub releases. Their binaries are not stored in this repository.

| Component | Source | License |
|---|---|---|
| REFramework | https://github.com/praydog/REFramework-nightly | MIT |
| OptiScaler | https://github.com/optiscaler/OptiScaler | See upstream license. Used as an upscaler only. |
| MAKO Renderer / MAKO FG | https://github.com/eugeniosegala/MAKO | GPL-3.0-or-later |
| cyboman FSR 4.1.2 Lite Lossy | https://github.com/zgauthier2000/fsr4-shader-performance-overrides | See upstream license and NOTICE.md. Modified upscaler DLL, single-player use only. |

The game graphics preset and all game-side effects are contained in `config/config.ini` and the consolidated Lua mod. No other mod files are installed or required.
